# Analyse des acheteurs de vélos (Excel)
Ce projet analyse un jeu de données de plus de 1000 clients afin d'identifier 
les profils types d'acheteurs de vélos. À partir de variables telles que l'âge, 
le revenu, le genre, la situation familiale, le niveau d'éducation, la profession 
et la distance de trajet, j'ai construit un tableau croisé dynamique et un 
tableau de bord interactif sous Excel pour visualiser les tendances d'achat 
(revenu moyen par genre, taux de conversion, répartition par région, etc.). 
L'objectif était de dégager des insights exploitables pour orienter des 
campagnes marketing ciblées.
